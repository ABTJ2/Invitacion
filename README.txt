INVITACIÓN WEB BASE

Qué trae:
- HTML, CSS y JavaScript puro.
- Diseño responsive, pensado principalmente para celular.
- Portada principal.
- Calendario visual.
- Cuenta regresiva real.
- Botón de ubicación.
- Confirmación por WhatsApp.
- Alias de regalo con botón para copiar.
- Código de vestimenta.
- Galería de fotos.
- Animaciones suaves al hacer scroll.

Cómo editar los datos:
1. Abrir script.js.
2. Cambiar los datos dentro de CONFIG:
   - nombre
   - fechaEvento
   - fechaTexto
   - horaTexto
   - salon
   - direccion
   - linkUbicacion
   - whatsapp
   - alias
   - vestimenta
   - marcaFooter

IMPORTANTE:
La fecha del evento va así:
2026-11-28T20:30:00-03:00
Año-mes-día, hora:minuto:segundo, zona horaria Argentina.

Cómo cambiar fotos:
Entrar a la carpeta img y reemplazar estos archivos:
- portada.svg por portada.jpg o portada.png
- foto1.svg por foto1.jpg o foto1.png
- foto2.svg por foto2.jpg o foto2.png
- foto3.svg por foto3.jpg o foto3.png
- foto4.svg por foto4.jpg o foto4.png

Si cambiás de SVG a JPG/PNG, también cambiá los nombres en index.html y style.css.
Ejemplo:
img/portada.svg -> img/portada.jpg

Cómo probar:
Abrir index.html en el navegador.

Cómo subir a Cloudflare Pages:
1. Crear repositorio en GitHub.
2. Subir todos estos archivos.
3. Entrar a Cloudflare Pages.
4. Conectar el repositorio.
5. Framework preset: None.
6. Build command: dejar vacío.
7. Output directory: dejar vacío o poner /.
8. Deploy.
